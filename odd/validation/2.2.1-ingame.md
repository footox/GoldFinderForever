# In-game validation for 2.2.1 (stage 2)

Offline suites, lint and the HTML mockup are stage 1 and already pass. This list is what only the game can prove.
Start with a FULL client restart (new files in the .toc). After each block, `/reload` and check `!BugGrabber.lua`.
Attach a screenshot for every item marked [shot].

## Auction house: live price check (GF-64)
- [ ] Open the auction house, GoldFinder tab. Last scan older than 10 minutes: first click on Post prints "Checking the live price...".
- [ ] A result arrives: chat line with the lowest price and the change vs the saved one; the button posts on the second click. [shot]
- [ ] Last scan fresh (press Scan first): Post takes ONE click.
- [ ] Option "Live check (min)" = 0: Post takes one click even with an old scan.
- [ ] Close the auction house while "Checking..." is pending: no error, nothing posted.
- [ ] Use a cheap item first; confirm the posted unit price matches the checked one.
